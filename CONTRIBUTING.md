# Contributing to HedgeBuddy

Thanks for your interest in contributing!

## Quick Start

### Python Library

```bash
cd python-lib
pip install -e .
pytest  # run tests
```

### Desktop App (Wails)

```bash
cd hedgebuddy-wails
wails dev  # hot-reload dev mode
```

## How to Contribute

1. **Report bugs** - [Open an issue](https://github.com/shakedex/hedgebuddy/issues)
2. **Suggest features** - [Start a discussion](https://github.com/shakedex/hedgebuddy/discussions)
3. **Submit code** - Fork, branch, PR

## Pull Request Checklist

- [ ] Tests pass
- [ ] Code follows existing style
- [ ] Tested on Windows/macOS
