A. Table, edit in place

Everything visible at once, like a spreadsheet: click a value to edit it right there with the editor its type needs (toggle, number, path picker, list). Fast for many small changes. In a narrow window the type and "required by" columns fold under the name.

C. Grouped by script

Variables sorted under the scripts that use them, so you set up "what the Slack script needs" in one place; missing ones sit right where they belong. Clear before a shoot, but a variable used by two scripts appears twice, and plain variables fall into an "unused" group.
