Open question: how much Claude activity to keep?

The spec asks for "the last MCP call". The MCP server runs as its own process, so it has to write calls somewhere for the app to show them. The recommendation: the server appends one line per tool call (time, tool, the target's name, ok or error, never argument values or secrets) to a small file in the data folder, kept to the last 200 calls. The app shows the latest few here. The alternative is a single "last call" line with no history.
