# Phase 5 mockups

These are the mockups from the phase 5 design exploration (2026-09-23). They are HTML fragments made for the brainstorming companion. Open them in a browser: the mockups use inline styles, so they still show correctly without the companion's frame.

The design they record is `../2026-09-23-phase5-desktop-app-design.md`. Where a mockup and the spec disagree, the spec wins.

| File | What it shows | Decision |
|---|---|---|
| `visual-direction.html` | Three visual directions for the home screen | B, "Instrument panel" |
| `navigation.html` | Navigation at wide and narrow widths | A, the adaptive sidebar |
| `variables.html` | Three layouts for Variables | B, list and detail |
| `scripts-runs.html` | Scripts and Runs as list and detail | Accepted as a starting point |
| `hedge-apps.html` | The Hedge apps screen | Accepted as a starting point |
| `connect-settings.html` | Connect and Settings | Accepted, with the Claude activity log kept to 200 calls |
| `home.html` | Home at wide and narrow widths | Accepted as a starting point |
| `icons-status.html` | Icon libraries and the status treatment | A, Lucide, with colour only for problems |

The earlier mockups use coloured dots (red, amber, green) and hand-drawn glyphs for status and navigation. `icons-status.html` replaces both. It uses Lucide icons with a word next to each, colours only failures (red) and things that need a look (amber), and shows count badges in the sidebar.
